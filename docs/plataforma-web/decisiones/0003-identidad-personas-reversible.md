# ADR-0003 — Identidad de personas probabilística y reversible

- Estado: aceptada
- Fecha: 2026-09-13

## Contexto

Hay códigos cambiantes, apodos y homónimos. Un jugador puede aparecer en varios equipos durante una
temporada.

## Decisión

El nombre genera candidatos; provincia, club, equipo, continuidad y conflictos aportan señales. Se
fusiona sólo con evidencia alta y margen claro o mediante decisión humana registrada. Las apariciones
no se reescriben: cambia su enlace a persona canónica.

## Consecuencias

La plataforma tolera identidades pendientes y puede deshacer errores sin perder datos.
